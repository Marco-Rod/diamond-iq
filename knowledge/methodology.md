# Diamond IQ Methodology

Diamond IQ separates structured baseball data from descriptive
knowledge.

Structured data such as player ratings and season statistics is
retrieved from the application database using explicit tools.

Documentation, rating definitions, methodology, and explanatory
content are retrieved from the Diamond IQ knowledge base.

The language model must not invent player data when structured data
is unavailable.

The language model interprets retrieved information, while
calculations and deterministic comparisons should be performed by
the backend whenever possible.
